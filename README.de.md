# Alook Browser Skill

[English](README.md) | [简体中文](README.zh-CN.md) | [繁體中文](README.zh-TW.md) | [日本語](README.ja.md) | [한국어](README.ko.md) | [Español](README.es.md) | [Français](README.fr.md) | [Deutsch](README.de.md) | [Português](README.pt-BR.md) | [Русский](README.ru.md)

KI-Agenten bedienen den echten Browser wie ein Benutzer, verwenden bestehende Anmeldesitzungen weiter und maximieren die Tokenersparnis.

Erfordert Alook Browser 1.0 oder neuer mit aktiviertem AI Control.

## Installation

Sende dies an deinen KI-Agenten:

> Installiere den offiziellen Alook Browser Skill von https://github.com/alook-browser/skill im benutzerweiten Skill-Verzeichnis dieses AI Agent und verwende `alook` als Ordnernamen. Aktiviere ihn für den aktuellen Agenten und prüfe, dass `alook` in der Liste der verfügbaren Skills erscheint.

Die optionale CLI-Installation erfordert Node.js 22.20.0 oder neuer:

```bash
npx skills add alook-browser/skill -g
```

## Verwendung

Bitte den Agenten, Alook für eine Browseraufgabe zu verwenden. Auf Hosts mit expliziten Skill-Befehlen kannst du `$alook` oder `/alook` verwenden.
