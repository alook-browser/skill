# Alook Browser Skill

[English](README.md) | [简体中文](README.zh-CN.md) | [繁體中文](README.zh-TW.md) | [日本語](README.ja.md) | [한국어](README.ko.md) | [Español](README.es.md) | [Français](README.fr.md) | [Deutsch](README.de.md) | [Português](README.pt-BR.md) | [Русский](README.ru.md)

Permet aux agents IA d’utiliser le navigateur réel comme un utilisateur, de réutiliser les sessions connectées et de maximiser l’économie de tokens.

Nécessite Alook Browser 1.0 ou version ultérieure avec AI Control activé.

## Installation

Envoyez ceci à votre agent IA :

> Installez le Alook Browser Skill officiel depuis https://github.com/alook-browser/skill dans le dossier Skills utilisateur de cet AI Agent, en nommant le dossier `alook`. Vérifiez ensuite que le Skill est disponible.

L’installation CLI facultative nécessite Node.js 22.20.0 ou version ultérieure :

```bash
npx skills add alook-browser/skill -g
```

## Utilisation

Demandez à l’agent d’utiliser Alook pour une tâche de navigation. Sur les hôtes proposant des commandes Skill explicites, utilisez `$alook` ou `/alook`.
