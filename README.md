# Alook Browser Skill

[English](README.md) | [简体中文](README.zh-CN.md) | [繁體中文](README.zh-TW.md) | [日本語](README.ja.md) | [한국어](README.ko.md) | [Español](README.es.md) | [Français](README.fr.md) | [Deutsch](README.de.md) | [Português](README.pt-BR.md) | [Русский](README.ru.md)

Let AI agents operate the real browser like a user, reuse existing login sessions, and maximize token savings.

Requires Alook Browser 1.0 or later with AI Control enabled.

## Install

Send this to your AI agent:

> Install the official Alook Browser Skill from https://github.com/alook-browser/skill in this AI agent's user-level Skill directory, using `alook` as the folder name. Enable it for the current agent, then verify that `alook` appears in the available Skill list.

Optional CLI installation requires Node.js 22.20.0 or later:

```bash
npx skills add alook-browser/skill -g
```

## Use

Ask the agent to use Alook for a browser task. On hosts with explicit Skill commands, use `$alook` or `/alook`.
