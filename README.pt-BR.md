# Alook Browser Skill

[English](README.md) | [简体中文](README.zh-CN.md) | [繁體中文](README.zh-TW.md) | [日本語](README.ja.md) | [한국어](README.ko.md) | [Español](README.es.md) | [Français](README.fr.md) | [Deutsch](README.de.md) | [Português](README.pt-BR.md) | [Русский](README.ru.md)

Permite que agentes de IA operem o navegador real como um usuário, reutilizem sessões já autenticadas e maximizem a economia de tokens.

Requer Alook Browser 1.0 ou posterior com o AI Control ativado.

## Instalação

Envie isto ao seu agente de IA:

> Instale o Alook Browser Skill oficial de https://github.com/alook-browser/skill no diretório de Skills do usuário deste AI Agent, usando `alook` como nome da pasta. Depois, confirme que o Skill está disponível.

A instalação opcional por CLI requer Node.js 22.20.0 ou posterior:

```bash
npx skills add alook-browser/skill -g
```

## Uso

Peça ao agente para usar o Alook em uma tarefa de navegador. Em hosts com comandos explícitos de Skill, use `$alook` ou `/alook`.
